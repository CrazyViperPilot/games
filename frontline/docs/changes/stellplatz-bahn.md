**Stellplatz braucht Verbindung zur Startbahn** (§15 „Stellplatz“): Ein Stellplatz lässt sich nur noch bauen, wenn eine seiner Zellen an eine Bahnzelle grenzt oder an eine Rollfeldzelle, von der eine Kette aus Rollfeld- und Bahnzellen zur Bahn führt; mit Baugebiet ersetzt das die Straßen-Anschlusspflicht des Stellplatzes, ohne Baugebiet gilt es ebenso. Meldung: „Stellplatz braucht eine Verbindung zur Startbahn (direkt oder über das Rollfeld)“.
