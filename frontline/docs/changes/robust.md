**Robustheit** (Fehlerbehebung): Die Linienrechnung für Mauern lief bei einer fehlenden oder ungültigen Koordinate endlos (das Spiel wäre hart eingefroren); sie liefert dann keine Zellen mehr, Bruchzahlen werden gerundet. Geprüft mit einem Dauerlauf (6 Partien × 40 min KI gegen KI auf Schwer, bis 333 Einheiten, Speichern und Laden im Gefecht): keine Ausnahmen, keine kaputten Zahlen.
