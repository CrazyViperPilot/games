# Iso-Grafiken (Kenney, CC0)

Quelle: Kenney (kenney.nl), Pakete „Isometric Buildings“, „Isometric City“ (Baum) und „Isometric Vehicles“, Lizenz CC0 (Lizenztexte in assets/LICENSES).
Ausgewählte Einzelbilder, unverändert; Dateinamen der Fahrzeuge nach Bildschirmrichtung (e, se, s, sw, w, nw, n, ne).
Eigene Entwürfe lassen sich austauschen: gleiche Dateinamen ersetzen oder die Listen in js/render/isosprites.js anpassen.
